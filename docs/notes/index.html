Hands-On RAG for Production 学习笔记

这是 O'Reilly《Hands-On RAG for Production》（Ofer Mendelevitch、Forrest Sheng Bao 著）的逐章中文笔记。 每一章都对照原书正文和仓库里的 notebook 整理：先用大白话讲清楚概念为什么存在，再拆解代码， 最后用术语表收尾 —— 从一条最小的 RAG 流水线，一路走到评估、智能体、多模态与知识图谱。
